## What the project is
Solo final project for IEOR 4723 (AI-Augmented Investment Management), modeled on handout example 6, "reverse stress testing agent", adapted to the NYISO power market. Claude proposes coherent scenarios as typed shock vectors (it never forecasts prices). A Python engine computes P&L on a synthetic 6-position book and scores how plausible each scenario is against 2019-2025 history. Baselines (random search, optimizer, conditional-Gaussian most-likely scenario) run at equal engine budget. Evaluation: distinct breaching scenarios (loss >= target AND rank q < 5% AND hard rules passed AND not implausible), coverage, coherence, analogue accuracy, ablations.
