The question

Start from the loss, search for the worlds

Conventional stress test

“Gas doubles and load jumps 10%. What do we lose?”

Reverse stress test

“We lose $5M, a quarter of capital. Which plausible worlds get us there, and through which positions?”

A regulatory expectation for banks, a useful exercise for any fund. The hard part: make an LLM propose worlds that are coherent, severe and not fantasy.

What the brief asks for

  1. Claude proposes narratively coherent scenarios
  2. Each is mapped to a structured shock vector via a schema
  3. A factor-based risk engine computes the P&L
  4. Results feed back so the agent refines toward breaches that stay plausible under historical covariance
  5. Deliverable: ranked scenarios with narratives, shock vectors, P&L decomposition, and an audit log of the search
