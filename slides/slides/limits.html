Limits

What this prototype does not establish

One seed per run. Breach counts move by 2-3 across draws.

Unequal budgets. Claude uses 42 engine calls, the baselines 144.

Single-channel book, not recalibrated on the final engine; the $5M target is reachable by ordinary worlds there.

Daily averaging hides hourly spikes of 3,000-4,500 $/MWh; P3 and P6 are understated.

No daily New York gas series: the basis is an explicit shock, not a factor.

LLM-only coherence grades. The pre-registered human rater is still pending; the demo lets one grade 20 scenarios blind.

Seven years of history, few independent extremes; q is a rank against 255 windows, not a probability.

Stated assumptions: $5,000/MWh cap; analogue figures verified for four events only.

Fixable next: ask the prompt to justify each shock’s size (the weakest coherence item), run several seeds, size a book on the final engine, add an hourly spike overlay.
