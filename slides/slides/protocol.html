Evaluation design

Three baselines at equal budget, and a bet placed before the runs

Random search

Shock vectors drawn inside the ranges. 144 engine calls per repeat.

Optimizer (SLSQP)

Minimize D² subject to loss ≥ $5M. 144 calls.

Conditional-Gaussian

The most likely factor state given the loss (Sparviero & Viola). 144 calls.

Claude agent

14 calls × 3 scenarios per repeat, uses only the engine calls it needs (42). 5 repeats, seed 0.

Hypothesis, written in the plan before any live run

The optimizer wins on D². Claude must win on coverage and coherence, or the result is reported as negative.

Metrics

Breaches per repeat · median D² and q · driver and channel coverage · stated versus engine loss · blind coherence (0-1) by a different model
