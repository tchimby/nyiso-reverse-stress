The solution

An agentic loop where Claude proposes and code decides

1. Propose

Claude writes 3 scenarios per call: narrative, typed shock vector, duration, analogue, confidence, own loss estimate

2. Gate

Schema, ranges, hard rules, price cap, check that a cited analogue exists

3. Engine

Shock to daily price path, P&L by position and by channel, loss versus target

4. Plausibility

D² on five daily factors, rank q against 255 historical windows, severity class

5. Feedback. Engine loss, plausibility class, one-at-a-time sensitivities and the soft-penalty state return to Claude for its next call. 14 calls per repeat; every call logged with prompt hash, messages and verdicts.

Claude (Sonnet 5.5; Haiku 5.5 as the cheap comparison). It never sees prices to forecast.
